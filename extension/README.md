# MailCraft Studio - Chrome Extension (Manifest V3)

1-Click Signature Switcher and Direct Injector for Gmail & Outlook Web.

---

## 🚀 How to Install in Google Chrome / Brave / Edge

1. Open your browser and navigate to: `chrome://extensions/`
2. Enable **"Developer mode"** in the top-right corner.
3. Click **"Load unpacked"** in the top-left corner.
4. Select this `extension/` folder.
5. The **MailCraft Studio** extension icon will now appear in your browser toolbar!

---

## ⚡ Features
- **1-Click Gmail Injection**: Click the extension popup on any open Gmail compose window to inject your rich HTML signature immediately.
- **Profile & Style Switcher**: Toggle seamlessly between *Developer Terminal*, *Academic Scholar*, *Corporate Executive*, and *Marketing Showcase* identities.
- **Clipboard Rich Text Copy**: Copy rendered signatures with one click for any email client.
- **100% Client-Side Privacy**: Operates fully in your browser with zero external telemetry.
