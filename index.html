Universal Email Client Setup

Step-by-step instructions for pasting your high-definition signature into any major email client.

$ cat docs/installation-matrix.md
100% SUCCESS RATE
01
Open MailCraft Studio and click "Copy Rich Signature".
02
Open Gmail in your web browser and click Settings (gear icon) > See all settings.
03
Scroll down to the Signature section and click + Create new.
04
Click inside the signature textarea and press Cmd + V (Mac) or Ctrl + V (Windows) to paste.
05
Under Signature defaults, select your new signature for new emails and replies, then click Save Changes at the bottom.
// GMAIL RETINA OPTIMIZATION: High-definition avatars render with subpixel smoothness and crisp vector icons automatically.
01
Open MailCraft Studio and click "Copy Rich Signature".
02
Open Apple Mail on your Mac and go to Mail > Settings (or Preferences) in the menu bar.
03
Select the Signatures tab, click the + button, and uncheck "Always match my default message font".
04
Click into the edit pane on the right, delete existing text, and press Cmd + V to paste.

03
Paste the signature into the editor with Ctrl + V or Cmd + V, then click Save.

// 05. TECHNICAL SPECIFICATIONS

Compiler Architecture Specs

Deep-dive into the rendering engine standards powering MailCraft.

// SPEC 01. CANVAS RASTERIZER

Retina Multiplier Algorithm

Source images are resampled via offscreen HTMLCanvasElement with bicubic filtering and pixel ratio compensation (up to 4x), generating base64 PNG data without server artifacts.

// SPEC 02. INLINE STYLING

Zero Class-Dependence

All styles are inlined at compile time into style="" attributes on nested tables to ensure 100% compliance across stripping webmail clients like Gmail web and Yahoo.

// SPEC 03. SECURITY & PRIVACY

Zero Egress Policy

Operates entirely in-browser. No API tokens, analytics trackers, or contact records are ever transmitted over external networks.

// SPEC 04. MSO COMPATIBILITY

Outlook Conditional Tags

Embedded <!--[if mso]> tags enforce rigid cell widths and prevent Microsoft Word rendering engine glitches.
